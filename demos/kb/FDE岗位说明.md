# FDE 前沿部署工程师岗位说明

FDE（Frontier Deployment Engineer，前沿部署工程师）负责把最新大模型能力快速、稳定地落地到真实业务场景，是连接模型研发与一线业务的桥梁角色。

核心职责包括：评估新模型与工具链在业务中的可用性，搭建可复用的部署与评测流水线，处理上线后的稳定性与降级问题，并把一线反馈回流给研发。

岗位要求通常覆盖：大模型应用经验（Prompt 工程、RAG、Function Calling、Agent 编排）、工程交付能力（Python、后端服务、数据库）、以及对 MCP 等新一代工具协议的理解。

相比纯算法研究，FDE 更看重工程落地与跨团队协调能力，软性经历（如流程统筹、临场接管、跨角色沟通）往往能成为差异化证据。
