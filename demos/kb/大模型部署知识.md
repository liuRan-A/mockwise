# 大模型应用与部署常识

检索增强生成（RAG）先根据用户问题从知识库检索相关片段，再把片段拼进提示词交给大模型生成答案，从而降低幻觉、引入私有知识。

Function Calling（函数调用）让大模型在回答时声明要调用的外部工具及其参数，由宿主程序执行后把结果回传，实现联网、计算、查库等能力扩展。

Agent（智能体）是在 Function Calling 之上的编排层：模型根据目标自主决定调用哪些工具、按什么顺序，循环执行直到完成任务，具备任务拆解与工作流编排能力。

MCP（Model Context Protocol，模型上下文协议）是一套开放标准，让大模型以统一方式连接各类数据源与工具，服务端暴露工具、客户端按协议调用，避免每个应用重复对接。
